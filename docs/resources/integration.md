# tofukit_integration (Resource)

Integration resource for representing external API/service dependencies

Integration resource for representing external API/service dependencies. Use this to document external services your project depends on (REST APIs, GraphQL APIs, SaaS platforms, etc.) with structured documentation references, environment URLs, SDK information, and example code.

## Example Usage

```hcl
# Basic REST API integration
resource "tofukit_integration" "open_meteo" {
  name        = "open-meteo"
  type        = "rest_api"
  description = "Open-Meteo Weather API"
  version     = "v1"

  docs = {
    main        = "https://open-meteo.com/en/docs"
    rate_limits = "https://open-meteo.com/en/features#rate-limits"
  }

  environments = {
    production = "https://api.open-meteo.com/v1"
  }
}

# GraphQL API with SDK info
resource "tofukit_integration" "github" {
  name = "github-graphql"
  type = "graphql_api"

  sdk = {
    python = {
      package  = "gql"
      version  = "3.4.0"
      docs_url = "https://gql.readthedocs.io/"
    }
  }
}
```
