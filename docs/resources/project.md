# tofukit_project (Resource)

Project resource that aggregates all component kits

Project resource that aggregates kits, features, stacks, and files into a complete software project managed by Claude.

## Example Usage

```hcl
resource "tofukit_project" "my_app" {
  name    = "my-application"
  version = "1.0.0"

  files = {
    "README.md" = {
      instructions = [{
        prompt = "Create project README"
      }]
    }
  }

  kits = [
    tofukit_language.python,
    tofukit_framework.flask
  ]

  requirements = [{
    name = "Setup"
    instructions = [{
      prompt = "Initialize project structure"
    }]
  }]
}
```

## Drift Detection

The project resource tracks file modifications outside of Terraform:
- `drift_detected` - Set to `true` when files are modified externally
- `drifted_files` - Lists paths of files that changed
- Running `tofu apply` after drift restores files to specification
